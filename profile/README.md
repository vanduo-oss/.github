## About

**Vanduo** is open-source software under [@vanduo-oss](https://www.npmjs.com/org/vanduo-oss): a **Vue 3** design system (**perspective**) and lightweight **web-AI** building blocks (**labs**) for semantic search, small on-device LLM tools, and related helpers that fit a web-oriented stack.

**npm keep list:** only `@vanduo-oss/vd3`, `@vanduo-oss/vd3-charts`, and `@vanduo-oss/vd3-flowchart`. Everything else under the scope is GitHub / `link:` siblings — not on the registry.

## Projects

Typed `Vd*` components, composables, and `--vd-*` design tokens. Peer dependency: `vue`.

### labs — web-AI components

Small, browser-friendly engines for hybrid search and on-device chat. Labs demos them at [labs.vanduo.dev](https://labs.vanduo.dev) and exists to support vanduo-oss web-oriented development. Consume via sibling `link:../vdl-*` (not npm).

| Repository | npm | Description |
|---|---|---|
| [vdl-hybrid-search](https://github.com/vanduo-oss/vdl-hybrid-search) | — | Headless hybrid fuzzy + semantic search with search guardrails (`link:`). |
| [vdl-ai-chat](https://github.com/vanduo-oss/vdl-ai-chat) | — | Headless on-device AI chat with FOSS LLM/tools guardrails and CSP-safe markdown (`link:`). |
| [vdl-cbun](https://github.com/vanduo-oss/vdl-cbun) | — | Labs canvas widgets (code-editor, draw, hex-grid, music-player) via sibling `link:` — not on npm. |
| [labs](https://github.com/vanduo-oss/labs) | — | Demo playground → [labs.vanduo.dev](https://labs.vanduo.dev) |
