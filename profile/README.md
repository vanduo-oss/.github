## About

**Vanduo** is open-source software under [@vanduo-oss](https://www.npmjs.com/org/vanduo-oss): a **Vue 3** design system (**perspective**), a Structured Phi icon set (**oola**, in progress), and lightweight **web-AI** building blocks (**labs**) for semantic search, small on-device LLM tools, and related helpers that fit a web-oriented stack.

## Projects

### perspective — Vue 3 design system

Typed `Vd*` components, composables, and `--vd-*` design tokens. Peer dependency: `vue`.

### labs — web-AI components

Small, browser-friendly engines for hybrid search and on-device chat. Labs demos them at [labs.vanduo.dev](https://labs.vanduo.dev) and exists to support vanduo-oss web-oriented development. VDL packages stay lean: hosts wire third-party libraries (Fuse.js, Transformers.js, LiteRT / WebLLM).

| [vdl-ai-chat](https://github.com/vanduo-oss/vdl-ai-chat) | [![npm](https://img.shields.io/npm/v/@vanduo-oss/vdl-ai-chat)](https://www.npmjs.com/package/@vanduo-oss/vdl-ai-chat) | Headless on-device AI chat with FOSS LLM/tools guardrails and CSP-safe markdown. |
